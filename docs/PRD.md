# 套利机会提醒神器 PRD

## 目标

帮助个人投资者快速发现基金套利相关机会，重点关注 LOF、ETF、QDII 等品种的溢价率、折价率、成交额、交易状态、申赎状态、申购限额、成本和资金占用周期。

## 用户场景

1. 开盘后快速查看当前溢价率最高的基金。
2. 只关注成交额足够大的品种，避免看起来有机会但流动性很差。
3. 关注 QDII、原油、黄金、纳指、标普等容易出现大幅溢价的品种。
4. 给自选品种设置阈值，达到条件后提醒。
5. 盘中需要快速刷新，不想手动翻网页。
6. 看到高溢价时，能立刻判断是否因为暂停申购、单日限额过低、赎回限制或跨境时滞导致无法套利。

## MVP 功能

### 看板

- 分类 Tab：全部、股债型 LOF、指数型 LOF、QDII-ETF、自选。
- 表格列：基金名称、代码、估值/净值、场内价格、溢价率、成交额、单日申购限额、申赎状态、成本/周期、执行结论。
- 支持点击表头排序。
- 高溢价红色，高折价绿色。
- 暂停、限购、场外限制等状态醒目标记。
- 达到价格条件但不可申购的品种标记为观察，不直接标记为可执行机会。

### 规则

- 溢价率大于等于阈值时标记为机会。
- 成交额小于阈值时降权。
- 暂停申购、暂停赎回、暂停交易时标记风险。
- 单日申购限额小于计划交易金额时，不标记为可执行机会。
- 扣除交易佣金、申购费、赎回费、现金替代等成本后，净溢价仍达到阈值才标记为可执行机会。
- 资金占用周期过长时标记时间风险。
- 自选品种优先展示。

### 提醒

- MVP：浏览器内提醒和列表高亮。
- 第二阶段：企业微信、Telegram、邮件或微信通知。

## 非目标

- 不承诺套利收益。
- 不做投资建议。
- MVP 不接自动下单。
- MVP 不处理复杂多账户和权限。

## 成功标准

- 用户打开页面后，10 秒内能看出当前最值得关注的 5 个品种。
- 用户能区分“可执行机会”和“看起来很高但做不了的高溢价”。
- 支持至少 30 个模拟或真实基金品种。
- 排序、筛选和高亮稳定可用。
- 后续可以替换真实数据源而不重写界面。
