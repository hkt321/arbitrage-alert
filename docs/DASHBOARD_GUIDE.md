# 看板字段说明

## 核心结论

看板不是直接告诉你“买”或“卖”，而是把套利前需要检查的条件压缩成几个字段：

```text
场内价格 - 估值/净值 - 成本 - 滑点 - 估值误差 = 可交易边际
```

如果 `可交易边际` 大于阈值，并且申赎、限额、成交额、盘口深度都满足要求，机会才可能进入 `可执行`。

## 字段解释

### 估值/净值

系统认为基金当前合理价值的估计。

- ETF 优先使用通达信返回的 IOPV / 参考净值。
- LOF / QDII-LOF 使用最近官方净值，再叠加指数、期货代理或汇率变化。
- 商品类 LOF 例如白银基金，第一版使用沪银期货候选合约做代理。

### 溢价率

```text
溢价率 = 场内价格 / 估值 - 1
```

正数表示场内交易价格高于估值，可能存在“申购/买入一篮子资产后卖出场内份额”的空间。负数则偏折价。

### 可交易边际

```text
可交易边际 =
  溢价率
  - 申购/交易成本
  - 盘口滑点
  - 估值误差安全垫
```

它比单纯溢价率更重要。比如溢价 6%，但估值误差安全垫 2%、费率 0.5%、盘口滑点 0.3%，真实可交易边际只剩约 3.2%。

### 成交额和卖一深度

- `成交额` 看当天这个品种是否活跃。
- `卖一深度` 估算你按卖一价能立刻成交的金额。

成交额大不代表你一定能成交，卖一深度太浅时，实际滑点可能吞掉套利空间。

### 置信度

估值模型的可靠程度。

- `高`：通常是境内 ETF，有 IOPV，误差较小。
- `中`：有相对可靠代理，但仍需校验。
- `低`：QDII、海外资产、商品代理、净值滞后明显，必须谨慎。
- `无`：暂不支持估值。

### 执行结论

- `可执行`：边际、申赎、限额、成交额、盘口、置信度都过了第一版规则。
- `观察`：有溢价或边际，但至少一个关键条件不满足。
- `普通`：暂时没有明显套利空间。
- `不可用`：当前模型不支持，或缺少关键数据。

当结论为 `可执行` 时，看板只展示基金公司或数据源返回的 `单日申购限额`。是否申购、申购多少、能否成交，需要你结合账户资金、盘口、费用和券商端实际提示自行判断。

## 为什么理由要看

执行结论旁边的理由是阻断项。例如：

```text
申购状态: closed
申购限额低于计划交易额
估值置信度: low
```

这类机会即使溢价很高，也不能直接当作可套利机会。很多高溢价来自暂停申购、限购、外汇额度、节假日或估值滞后。

## 使用建议

第一版建议按这个顺序看：

1. 先看 `执行结论`，只把 `可执行` 和 `观察` 当重点。
2. 再看 `可交易边际`，不要只看溢价率。
3. 再看理由，确认是不是申购关闭、限额太低、置信度太低。
4. 最后看成交额和盘口深度，判断实际资金能不能进出。

当前系统是提醒工具，不是自动交易工具。下单前仍需在券商软件里确认申赎状态、费用、额度、成交价格和到账周期。
